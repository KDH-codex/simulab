개인정보처리방침

개정일 2026-10-23

선택 방문 통계와 원격 랭킹의 신규 전송은 운영 정보와 서버 설정을 확인할 때까지 기본 보류 상태입니다. 아래는 이번 개편 코드의 처리 방식입니다. 기존 서버 기록의 보관·파기 설정과 운영 연락처 확인은 아직 남아 있습니다.

1. 서비스 기능과 기기 내 저장

계산은 주로 브라우저에서 수행합니다. 최근 사용한 도구, 저장한 계산 조건, 이름 후보와 게임 기록은 이용자의 브라우저 저장소에 보관될 수 있습니다. 방문 통계에는 계산 입력값, 검색한 이름, 건강·소득 수치를 보내지 않도록 구성했습니다.

브라우저의 사이트 데이터 삭제 기능으로 기기 저장 자료를 삭제할 수 있습니다. 홈의 최근 사용 기록과 이름 후보는 각 화면에서도 지울 수 있습니다. 기기 저장 자료는 기기를 바꾸거나 사이트 데이터를 지우면 복구되지 않을 수 있습니다.

2. 선택 방문 통계

기존 버전은 방문 기록과 이용 이벤트를 Supabase로 전송했습니다. 새 버전은 운영 이메일·저장 지역 등 설정 확인 전에는 신규 통계를 전송하지 않습니다. 이후 통계를 활성화하면 이용자가 허용한 경우에만 무작위 세션 ID, 도구 ID, 고정된 이용 행동 코드와 서버 등록 시각을 전송하도록 구성했습니다. 전체 referrer, user_agent, 자유 입력 이벤트 라벨은 전송하지 않습니다.

통계 목적은 도구 이용 횟수와 개선 우선순위 파악입니다. 원시 통계 보관 목표는 30일이며, 기존 저장분의 실제 파기와 자동 정리 설정은 아직 확인 중입니다. 자동 파기가 이미 적용됐다는 의미는 아닙니다.

3. 게임 기록과 공개 랭킹

현재 기본 설정에서는 기록을 기기에 저장합니다. 원격 랭킹을 활성화할 때에는 이용자가 등록을 선택한 닉네임·게임 종류·점수와 중복·빈도 확인용 무작위 식별자를 Supabase에 전송합니다. 서버가 등록 시각과 표시 문자열을 생성합니다. 닉네임, 점수, 게임 종류, 등록일은 다른 이용자에게 공개됩니다. 실명·연락처 등 개인 정보를 닉네임으로 쓰지 마세요.

기기 기록을 지워도 이미 등록된 원격 기록까지 삭제되는 것은 아닙니다. 기존 원격 기록의 삭제 요청 창구와 보관기간은 운영 설정에서 확정할 사항입니다.

4. 외부 서비스와 국외 처리

서비스용도와 현재 상태
Cloudflare홈페이지 제공. 접속 처리 과정에서 네트워크·보안 로그가 처리될 수 있습니다.
Supabase관리자 인증과 통계·랭킹 저장. 사용자가 제공한 프로젝트 화면의 지역은 ap-south-1(뭄바이)입니다. 실제 연결 프로젝트와 기존 데이터 보관·파기 설정은 추가 확인이 필요합니다.
Google AdSense광고 승인 대기 상태입니다. 개편본에서는 광고 스크립트의 자동 로드를 중단하고 소유권 확인용 메타 태그와 ads.txt를 유지합니다.
외부 폰트 제공 서비스화면 글꼴 제공을 위해 CDN에 접속할 수 있으며 요청 정보가 해당 서비스로 전달될 수 있습니다.

각 서비스의 실제 계약 관계, 저장 지역과 국외 이전에 필요한 상세 고지는 운영 설정 확인 후 보완해야 합니다. 현재 방침에 미확인 국가나 보관기간을 확정 사실로 기재하지 않습니다.

5. 광고 쿠키와 선택

향후 Google 광고를 활성화하면 Google 및 제3자 광고 공급업체가 이전 사이트 방문 이력을 바탕으로 광고 쿠키를 사용할 수 있습니다. 이용자는 Google 내 광고 센터에서 개인 맞춤 광고를 조정하고 브라우저에서 쿠키를 차단할 수 있습니다. 광고 활성화 전 실제 공급업체와 적용 지역의 동의 요건을 반영하겠습니다.

기존 안내 배너를 닫았다는 기록은 선택 방문 통계 허용으로 이전하지 않습니다.

6. 권리행사와 운영 문의

열람·정정·삭제 등 개인정보 관련 문의를 위한 공개 연락처는 현재 준비 중입니다. 문의 이메일 준비 중. 정상 수신을 확인한 운영 연락처를 마련하고 기존 원격 자료의 권리행사 절차를 확정한 뒤 선택 수집을 재개해야 합니다.

이 문서가 아직 확인되지 않은 운영 설정이나 법적 적합성을 보증하지는 않습니다. 설정을 확정하면 개정일과 변경 내용을 함께 안내합니다.
