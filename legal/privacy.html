개인정보처리방침

개정일 2026-10-28

선택 방문 통계는 이용자가 허용한 경우에만 수집합니다. 허용 여부는 개인정보 설정에서 언제든지 바꿀 수 있습니다. 원격 랭킹의 신규 전송은 현재 보류 상태입니다. 기존 서버 기록의 보관·자동 파기 설정은 확인 중입니다.

1. 서비스 기능과 기기 내 저장

계산은 주로 브라우저에서 수행합니다. 최근 사용한 도구, 저장한 계산 조건, 이름 후보와 게임 기록은 이용자의 브라우저 저장소에 보관될 수 있습니다. AI 사망토론의 시범 판정에는 선택한 모델, 작성한 한 줄 판정과 저장 시각이 해당 브라우저의 로컬 저장소에 남으며, 공개 댓글 서버나 득표 집계 서버로 전송하지 않습니다. 브라우저의 사이트 데이터 삭제로 지울 수 있습니다. 방문 통계에는 계산 입력값, 검색한 이름, 건강·소득 수치를 보내지 않도록 구성했습니다.

브라우저의 사이트 데이터 삭제 기능으로 기기 저장 자료를 삭제할 수 있습니다. 홈의 최근 사용 기록과 이름 후보는 각 화면에서도 지울 수 있습니다. 기기 저장 자료는 기기를 바꾸거나 사이트 데이터를 지우면 복구되지 않을 수 있습니다.

도구 링크 공유

공통 링크 복사 기능은 입력한 출생 정보·금액·건강 조건을 제외하고 도구 주소만 복사합니다. 새로 개편한 건강·사주·금액 도구는 입력값을 자동 저장하지 않습니다. 행사 필터나 가상 게임 결과 등 별도 공유 기능은 해당 화면의 안내를 확인하세요. 과거에 입력 조건을 포함해 공유한 링크와 외부에 남은 사본까지 소급해 삭제하는 것은 아닙니다.

2. 선택 방문 통계

기존 버전은 방문 기록과 이용 이벤트를 Supabase로 전송했습니다. 현재는 이용자가 통계를 허용한 경우에만 무작위 세션 ID, 도구 ID, 고정된 이용 행동 코드와 서버 등록 시각을 기록합니다. 전체 referrer, user_agent, 자유 입력 이벤트 라벨과 계산 입력값은 전송하지 않습니다. 도구 경로와 첫 방문 여부는 서버에서 생성합니다. 관리자·정책 페이지의 방문 통계는 수집하지 않습니다.

통계 목적은 도구 이용 횟수와 개선 우선순위 파악입니다. 원시 통계 보관 목표는 30일이며, 기존 저장분의 실제 파기와 자동 정리 설정은 아직 확인 중입니다. 자동 파기가 이미 적용됐다는 의미는 아닙니다.

3. 게임 기록과 공개 랭킹

현재 기본 설정에서는 기록을 기기에 저장합니다. 원격 랭킹을 활성화할 때에는 이용자가 등록을 선택한 닉네임·게임 종류·점수와 중복·빈도 확인용 무작위 식별자를 Supabase에 전송합니다. 서버가 등록 시각과 표시 문자열을 생성합니다. 닉네임, 점수, 게임 종류, 등록일은 다른 이용자에게 공개됩니다. 실명·연락처 등 개인 정보를 닉네임으로 쓰지 마세요.

기기 기록을 지워도 이미 등록된 원격 기록까지 삭제되는 것은 아닙니다. 기존 원격 기록의 삭제 요청 창구와 보관기간은 운영 설정에서 확정할 사항입니다.

4. 외부 서비스와 국외 처리

서비스용도와 현재 상태
Cloudflare홈페이지 제공. 접속 처리 과정에서 네트워크·보안 로그가 처리될 수 있습니다.
Supabase관리자 인증과 동의한 방문 통계 저장. 실제 연결 프로젝트의 지역은 ap-south-1(인도 뭄바이)입니다. 통계는 이 지역의 Supabase 프로젝트에 저장됩니다. 원격 랭킹 신규 전송은 현재 꺼져 있으며, 기존 데이터 보관·자동 파기 설정은 확인 중입니다.
Google AdSense광고 승인 대기 상태입니다. 소유권 확인용 메타 태그와 ads.txt를 유지합니다. 광고 자리에는 준비 중 표시만 제공하며, 광고 스크립트와 광고 쿠키를 새로 요청하지 않습니다. Google 승인만으로 이 사이트의 광고 코드가 자동 활성화되지는 않습니다.
외부 폰트 제공 서비스화면 글꼴 제공을 위해 CDN에 접속할 수 있으며 요청 정보가 해당 서비스로 전달될 수 있습니다.

Supabase 통계 저장 지역은 인도 뭄바이입니다. 각 서비스의 실제 계약 관계와 아직 확인 중인 보관·자동 파기 설정에 관한 내용은 확인 결과에 따라 보완합니다.

5. 광고 쿠키와 선택

향후 Google 광고를 활성화하면 Google 및 제3자 광고 공급업체가 이전 사이트 방문 이력을 바탕으로 광고 쿠키를 사용할 수 있습니다. 이용자는 Google 내 광고 센터에서 개인 맞춤 광고를 조정하고 브라우저에서 쿠키를 차단할 수 있습니다. 광고 활성화 전 실제 공급업체와 적용 지역의 동의 요건을 반영하겠습니다.

기존 안내 배너를 닫았다는 기록은 선택 방문 통계 허용으로 이전하지 않습니다.
