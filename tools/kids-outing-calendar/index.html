왜 예전 행사나 ‘데이터 동기화’ 버튼이 없어졌나요?

올해 공식 근거를 확인하지 못한 기존 항목은 공개 달력에서 제외했습니다. 기존 버튼은 실시간 공공데이터 연동이 아닌 브라우저 JSON 가져오기 기능이었습니다. 현재는 검토한 정보만 게시하며, 예전에 브라우저에 저장한 사용자 자료는 공식 목록과 합치지 않습니다.
