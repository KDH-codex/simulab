누가 같은 금액을 부담하나요?

여러 사람이 같은 비용을 나눌 때 사용하는 균등 정산입니다. 참석자별 식사량이나 음주 여부를 점수로 추정하지 않고, 부담하기로 합의한 사람 수로 총액을 나눕니다. 가족 여행 동행 비용이라면 아이를 같은 부담 인원에 포함할지 먼저 정해야 합니다.

입력 전에 결제액을 확정하세요

영수증에서 실제 결제된 원 단위 총액을 확인하세요. 할인 전 가격에 쿠폰을 다시 빼거나 이미 돌려받은 환불액을 포함하면 맞지 않습니다. 여러 차례 결제했다면 각 영수증을 합산하고, 개별 구매분은 공동 정산 총액에서 제외할지 먼저 합의하세요.

10만원을 세 명이 나누는 예시

100,000원을 3명으로 나눈 몫은 33,333원이고 나머지는 1원입니다. 따라서 1명은 33,334원, 2명은 33,333원을 부담하면 합계가 정확히 10만원이 됩니다. 모두 33,334원을 내게 하면 2원이 더 걷히므로 기본 금액과 추가 1원을 낼 인원을 나누어 표시합니다.

반올림 때문에 생기는 잔돈

화면에 같은 금액을 표시하는 것만으로 정산 합계가 맞지는 않습니다. 이 도구는 정수 나눗셈의 몫과 나머지를 사용해 원 단위 합계를 보존합니다. 추가 부담 순서는 추첨으로 정하지 않으며 참여자끼리 정하면 됩니다. 총액이 0원이면 모든 사람의 부담도 0원입니다.

이 도구가 다루지 않는 정산

한 사람이 선결제한 금액의 상계, 여러 사람 사이 최소 송금 횟수, 참석 시간이 다른 사람의 가중 분담은 계산하지 않습니다. 그런 모임에서는 먼저 분담 원칙을 정한 뒤 항목별로 나누어 계산하세요. 이름·전화번호·계좌번호를 넣을 필요가 없으며 링크를 공유해도 입력한 총액은 함께 보내지 않습니다.
