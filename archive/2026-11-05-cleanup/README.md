# 이전 코드·기획·시안 보관함

현재 페이지·생성기·테스트가 사용하지 않는 것으로 확인한 파일 62개를 2026-11-05에 모았다. 삭제한 파일은 없다. 이동 전후 SHA256이 모두 일치한다.

- `assets/js/`, `assets/css/`: 이전 `festa-*` JS·CSS 10개. 현재는 `festival-*` 소스를 사용한다.
- `assets/img/festivals/`: 정본과 공개 페이지에 연결되지 않은 이미지 후보 25개. 다시 사용하려면 원본 출처·재사용 권리와 실제 행사 관련성을 확인한다. 현재 사용 중인 Pexels 참고 이미지는 이동하지 않았다.
- `docs/`: 이전 Stitch 프로젝트와 옛 번들을 지시하는 전달·구현 문서 3개.
- 루트의 이미지·HTML: 옛 시뮬랩 미리보기 12개.
- 루트의 Markdown·텍스트: 초기 기획·구조·진단 자료 6개.
- `design-history/`: 작업 폴더 상위에 흩어져 있던 브랜드 탐색 자료 6개.

`manifest.json`이 전체 목록·원래 위치·체크섬·이동 이유를 담는다. 상위 작업 폴더 기준 `originalPath`로 복원할 수 있다. 복원 대상에 파일이 이미 있으면 덮어쓰지 말고 먼저 차이를 확인한다. 보관된 HTML과 코드는 이력 자료이며 현재 구현이나 사실 정보의 기준이 아니다.

이 보관함은 `scripts/build-site.mjs`의 공개 폴더 목록에 없고 `.assetsignore`, `.wranglerignore`에서도 제외한다. 현재 사이트 안내는 `../../docs/workspace-guide.md`를 읽는다.
