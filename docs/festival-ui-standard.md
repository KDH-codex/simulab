# 이번주 축제 UI 기준

새 메뉴 탭을 만들 때 이 문서를 현재 기준으로 사용한다. 이전 결정의 경위는 [UI 구현 기록](festival-ui-implementation-20261105.md)과 [운영 문서](festival-platform-maintenance.md)에 있다.

## 제목과 타이포그래피

- 브랜드 표기는 **이번주 축제**다. 브랜드와 홈 대표 제목은 SBAggro Bold, 일반 제목은 Paperlogy, 본문은 Pretendard Variable을 사용한다. 같은 출처에서 공식 Pretendard 분할 폰트를 제공하고 전체 폰트를 선행 다운로드하지 않는다.
- 팔레트는 주황 `#F97316`, 인디고 `#6366F1`, 보라 `#7C3AED`를 기본으로 쓴다. 제목의 기본색은 사이트의 짙은 글자색을 따르고 핵심 구절에만 주황을 적용한다.
- 홈의 첫 화면은 왼쪽 살구빛 `#FFE3CF`와 오른쪽 라벤더빛 `#E8DDFF`를 밝은 바탕으로 흐리게 연결한다. 좁은 화면에서는 색이 대표 사진 위아래 여백에서도 보이도록 범위를 조절한다. 정적인 CSS 그라데이션을 사용한다.
- 홈은 **이번 주 / 어디 갈까?** 두 줄이다. `splitHeading()`으로 한글 음절과 문장부호를 하나씩 표시한다. 공백은 그대로 두며 각 글자는 **125ms 간격**, **600ms** 동안 아래 **24px**, 회전 **10도**에서 제자리로 들어온다. 처음 진입할 때 한 번만 재생한다.
- 지역별 탐색은 **어디로 / 떠나볼까요?**, 축제 달력은 **어느날 / 떠나볼까요?** 두 줄이다. 첫 줄은 짙은 글자색, 둘째 줄은 전체 주황색이다.
- 이번 주말은 **이번 주말, / 즐거운 일이 기다려요.**를 사용한다. 둘째 줄의 **기다려요.**만 주황색이다.
- 탐색 탭은 `scripts/festival-pages.mjs`의 공통 `intro()`를 사용한다. 제목은 줄마다 텍스트 조각을 배열로 넘기고 강조 조각에 `accent: true`를 지정한다. 예를 들어 `[[{text:'어디로'}],[{text:'떠나볼까요?',accent:true}]]`는 두 줄을 뜻한다.
- 영문 소제목과 큰 제목은 각각 **60ms 간격**으로 글자를 표시하고 현재 글자 뒤에 `|` 커서를 붙인다. 완성 문구의 글자들은 처음부터 실제 문서 흐름에서 높이를 차지한다. 애니메이션은 같은 글자의 투명도만 바꾸고, 커서의 폭도 미리 확보해 설명문이나 아래 필터가 밀리지 않게 한다. 스크린리더에는 문장 전체를 한 번만 제공한다.

## 카드, 탐색과 이미지

- 공통 헤더의 모바일·데스크톱 **앱설치** 버튼은 브라우저와 설치된 앱 양쪽에서 표시한다. 브라우저에서는 설치 창을 먼저 사용하고, 창을 열 수 없으면 기기에 맞는 북마크 저장 안내를 표시한다. 설치된 앱에서는 현재 앱으로 열려 있음을 안내한다.

- 카드 진입 모션은 보이는 묶음마다 **100ms 간격**, **450ms**, 아래 **24px**에서 위로 등장한다. 필터로 교체된 카드에도 적용한다.
- 마우스 호버는 카드 **8px 상승**, 사진 **1.04배**, 보라색 그림자 **25px**를 사용한다. 터치 화면에서는 호버 모션을 적용하지 않는다.
- 홈 대표 사진은 **3초** 자동 전환, 수동·자동 모두 **800ms 페이드**를 사용한다. 이전 이미지를 불투명하게 남긴 채 새 이미지를 덮는다. 읽는 중 포인터·키보드 초점·모달·화면 밖·숨은 탭의 정지 조건과 정지 버튼을 유지한다.
- 원래 필터를 지난 뒤에만 고정 필터를 표시한다. 활성 키워드·무료·보관·기간 조건을 보여주고 해제할 수 있게 한다. 가로 카드 피드에는 내부 스크롤과 앞뒤 이동 버튼을 둔다. 상세 모달은 키보드로 닫을 수 있어야 하고 닫을 때 초점을 돌려준다.
- 상단 메뉴는 현재 탭을 표시한다. 지역 탐색은 서울·경기·강원·충청·전라·경상·제주의 7개 권역을 공통 모델에서 읽는다. 달력은 월간으로 열고 월간·주간 전환, 주차 선택, 날짜 선택과 다시 누르면 해제하는 흐름을 유지한다. 주간 7열은 좁은 화면에서 달력 안에서만 가로로 스크롤한다.
- 상세 모달의 일정·예약·장소·출처 탭과 모바일 하단 시트를 재사용한다. 날씨는 기존 출처와 대표 지점 예보 표기를 사용한다.
- 카드는 공통 이미지 함수와 태그를 재사용한다. 가벼운 WebP를 우선 사용하고, 참고 사진에는 **주제 참고 · 현장 사진 아님**과 출처를 표시한다. 사진이 없으면 테마 일러스트를 사용한다. 운영 지도는 권역 선택용 개략도다. 권역 버튼은 터치·호버·모션 줄이기 설정에서 같은 위치를 유지한다.
- 기기의 **모션 줄이기** 설정에서는 제목·카드가 즉시 완성된 상태로 보이고 페이드·이동을 생략한다. 자바스크립트가 없어도 제목은 읽을 수 있어야 한다.

## 새 탭 검증

- 할인·쇼핑은 공통 헤더의 다섯 번째 탭이다. 긴 다국어 메뉴는 헤더 안에서 가로 스크롤하고 현재 메뉴를 표시한다. 상품 사진을 확보하지 않은 할인 카드는 자체 분류 배경·브랜드 이름과 안내 카드 고지로 구성한다. 축제 보관함과 할인 보관함은 별도로 유지한다. 세부 운영 기준은 [할인·쇼핑 운영 문서](shopping-sales-maintenance.md)를 따른다.

### 다국어·추천 배지

- 헤더 언어 선택은 한국어·영어·일본어·중국어 간체·번체다. `lang` 쿼리 → 저장한 선택 → 지원되는 브라우저 언어 순으로 결정한다. 내부 필터 값·행사 ID·지도 검색용 장소 원문은 한국어 정본을 유지하며 표시 문구만 바꾼다.
- `assets/js/festival-i18n.js`는 UI 문구, `festival-event-locales.js`는 행사별 4개 언어 이름과 주제 요약을 관리한다. 번역은 공인 번역·상세 프로그램 직역이 아닌 탐색용 이름·요약이다. 세부 예약·참여 조건은 원문으로 보존하고 상세 화면에 번역 범위를 표시한다. 신규 행사 등록 시 번역 ID도 추가해야 한다.
- 언어 변경·이동·공유에서 날짜·지역·보관함·해시와 선택 언어를 유지한다. 브라우저 저장소를 쓸 수 없어도 URL로 언어가 전달되어야 한다. 공식 사이트와 지도 등 외부 URL은 수정하지 않는다.
- HOT은 `festival-highlights.js`의 출처·이유가 있는 편집 선정 행사에만 붙인다. 실시간 인기·방문자 수·순위로 표현하지 않는다. 종료 다음 날과 취소 행사에는 배지를 숨긴다. 홈의 추천 피드와 공통 카드·상세 사진에 같은 규칙을 적용한다.
- 긴 영문과 일본어·중국어, 모바일 320/390px, 언어 전환 뒤 필터·달력·모달·보관함, 원문 출처·AI 이미지 고지를 확인한다. 언어별 페이지를 별도로 서버 생성하지 않으므로 canonical은 한국어 기본 URL을 유지하며 가짜 hreflang을 추가하지 않는다.

1. 데스크톱과 모바일 **320px, 390px**에서 제목 두 줄, 구절별 색, 설명과 필터 간격, 가로 넘침을 확인한다.
2. 일반 모션에서 타이핑 중과 완료 후의 제목 높이와 설명 위치가 같은지 확인한다. 모션 줄이기에서도 제목 전체가 한 번만 표시되는지 확인한다.
3. 탭의 실제 필터·카드·모달을 확인하고, `npm test`, `npm run build`, `node scripts/check-public.mjs`를 실행한다.
