# 이번주 축제 · 상세 UI 수정

2026-11-04 사용자 요청을 적용한다. 이번 변경은 홈페이지 구조·상호작용·표시 방식에 한정하며 축제 정본의 내용·확인일과 다른 8개 분야의 정기 수집 중단 상태를 유지한다.

## 적용 내용

1. 표기: 이번주 축제. 제목·메뉴·푸터·상세·매니페스트·공유 이미지에 같은 표기를 사용한다.
2. 브랜드·메인 문구: 샌드박스 어그로체 Bold. 제목: 페이퍼로지 Bold/ExtraBold. 일반 글씨: 부산단디명조 Medium/Bold. 지정한 눈누 738/1456/1990의 원본 웹폰트를 수정 없이 자체 제공한다.
3. 카드 피드: IntersectionObserver로 보이는 카드부터 65ms 간격, 최대 390ms 지연의 순차 등장 효과를 적용한다. 모션 줄이기 환경에서는 이동 효과 없이 내용을 표시한다.
4. 대표 카드: 3초 자동 전환과 이전·다음·도트에 같은 전환 함수를 사용한다. 일시정지 버튼을 제공하고 포인터·키보드로 읽는 중, 상세 모달·다른 탭·화면 밖에서는 타이머를 멈춘다. 모션 줄이기는 전환 이동 효과를 생략한다.
5. 태그: 확인된 행사명·프로그램·지역·테마에서 추출한다. 비용·주차·연령 등의 새로운 사실을 추정하지 않는다. 클릭하면 해당 단어로 현재 목록을 필터링하며 해제·조건 초기화를 제공한다.
6. 고정 필터: 기존 필터를 지나면 상단 메뉴 대신 작은 지역·테마 필터가 나타난다. 원본과 상태를 공유하며 전체 조건 버튼으로 원래 필터에 돌아간다. 스크롤을 위로 되돌리면 일반 메뉴가 복구된다.
7. 달력: 기본 월간, 월간/주간 일정 단일 세그먼트. 사이드바의 주차 선택은 주간으로 전환한다. 월 경계를 넘는 주도 7일 전체 데이터를 사용하며 지정 운영일을 보존한다. 주간 표의 시작/종료는 날짜 경계이며 실제 개·폐막식 시간이라는 뜻이 아니다.
8. 주간 카드: 선택한 주 또는 날짜의 고유 행사를 가로 피드로 표시한다. 시간표를 임의로 만들어 배치하지 않고 원본의 운영 시간 설명을 그대로 제공한다.
9. 날씨: MET Norway Locationforecast를 기존 Cloudflare Worker의 /api/weather로 연결한다. 새 계정·키·유료 서비스·호스팅을 생성하지 않는다.

## 날씨 제공 원칙

- 기본은 서울 대표 지점. 경기/강원/충청/전라/경상/제주 선택 시 수원/강릉/대전/광주/부산/제주 대표 지점으로 바뀐다. 날씨 기준 도시만 별도로 선택할 수도 있다.
- 현재 위치·GPS·행사 좌표로 표시하지 않는다. 고정된 7개 대표 지점만 허용하며 임의 위도·URL을 프록시하지 않는다.
- 한국시간으로 날짜를 나누고, 제공된 미래 시각 중 낮 12시에 가장 가까운 기온·날씨를 일자별 대표 예보로 정리한다. 이미 지난 오늘의 낮 시각은 만들지 않고 남은 예보 시각을 사용한다.
- 일 최고·최저 기온, 관측 실황, 강수 확률, 행사장 날씨로 설명하지 않는다. 날짜별 실제 기준 시각은 툴팁·접근성 레이블로 제공한다.
- 원본의 갱신 시각·제공 범위를 표시한다. 과거·예보 범위 밖·연결 실패는 서로 구분하며 맑음이나 0도로 대체하지 않는다.
- 식별 가능한 User-Agent로 요청하고 제공자의 Expires까지 캐시한다. 브라우저는 같은 사이트의 프록시를 사용하여 이용자 IP와 선택 정보를 외부 예보 API에 직접 보내지 않는다.
- 출처 MET Norway, CC BY 4.0 및 대표 예보로 재구성했다는 사실을 화면에 표시한다.
