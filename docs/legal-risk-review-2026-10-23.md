## 판단과 범위

우선 수정할 항목이 있다. 특히 사주·성향에 따른 실제 투자상품 추천, 건강 효과의 보장 표현, 현행 기준과 다른 급여·수당 계산, 증빙이 부족한 공식 통계·실측 표시는 면책문구를 추가한 뒤에도 남아 있다. 이전 작업은 고지의 가시성을 보완한 것이며 본문·수식 전체의 법률 적합성 검증을 완료한 것이 아니다.

51개 공개 도구의 문구·공유·외부 통신 경로를 일괄 점검하고, 위험이 높은 항목의 소스와 공식 기준을 대조했다. 운영 사이트의 사주 추천 결과와 카페인 수면 판정도 직접 확인했다. 모든 수식을 전수 검산하거나 상표 등록·이용허락 계약을 확인한 것은 아니다. 운영 DB 정책과 기존 저장분은 조회하지 않았다. 아래는 실제 오류와 법적 검토가 필요한 가능성을 구분한 운영 판단이며 위법 확정 판정은 아니다.

## 1. 먼저 축소할 기능: 사주·투자 성향의 금융상품 추천

대상: [사주 재물운](https://simulab.kr/tools/saju-wealth-sim/), [투자 동물 테스트](https://simulab.kr/tools/invest-animal-mbti/), [주식·ETF 퀀트](https://simulab.kr/tools/leverage-etf-sim/).

- 사주 결과는 생년월일시·성별을 받아 실제 종목·ETF를 추천한다. 소스에는 TQQQ·SOXL·NVDA·SCHD·JEPI/JEPQ 등이 있으며, 운영 화면에서도 Realty Income O·SCHD 추천을 확인했다. 본문에는 특정 오행에 고배당주·리츠를 30% 이상 배분하라는 설명도 있다. 상단의 ‘투자 조언을 제공하지 않는다’는 안내와 실제 결과가 충돌한다.
- 투자 동물 테스트에는 채권형 ETF의 원금이 거의 보장된다는 선택지, 결과별 실제 추천 상품, 급등 코인·공모주·배당락 매매 추천이 있다. 자산의 원금 보장을 오해하게 할 수 있다.
- 퀀트 도구는 단순 계산을 넘어 분할 매수 골든존, 현금 비중 확대, 최적 레버리지 등 행동 지침을 출력한다. 데이터 검증 문제도 4번에 해당한다.

권고: 사주·성향 테스트의 실제 금융상품명·매매·배분 추천을 우선 제거하고 오락용 성향 설명으로 제한한다. 퀀트는 원자료를 검증한 교육용 지표 설명과 가정 계산으로 한정한다. 유료 구독·회원별 상담·매수/매도 신호 판매·제휴 판매로 확장하기 전 투자자문업 등 해당 여부를 별도 검토한다. 무료 계산기나 광고 수익만 있다는 사정으로 등록 의무의 유무를 단정하지 않는다. 금융위는 대가·채널·개별 조언 여부 등에 따라 투자자문과 유사투자자문을 구분한다. [금융위 공식 설명](https://www.fsc.go.kr/no010101/82887)

## 3. 건강 도구: 안전·처방·효과 단정

대상: [카페인](https://simulab.kr/tools/caffeine-sleep-calc/), [BMR·TDEE](https://simulab.kr/tools/diet-bmr-tdee-calc/), 러닝·기대수명·애착 유형.

카페인 운영 화면은 50mg을 안전 기준으로 삼고 수면 안전 판정·REM 보장도를 표시한다. 결과에는 깊은 수면을 방해받지 않는다는 단정이 있다. 이는 계산식으로 확인한 개인의 임상적 안전이 아니다. EFSA도 카페인의 수면 영향에 개인차가 있음을 전제로 설명한다. 그 자료로 사이트의 잔여량 50mg 기준이 보장된다고 해석할 수 없다. [EFSA 설명](https://www.efsa.europa.eu/en/topics/topic/caffeine)

BMR·TDEE는 ‘처방 결과’와 칼로리만으로 매주 근육량 증가가 가능하다는 결과를 출력한다. 애착 테스트의 진단서·갈등 처방전, 기대수명을 개인의 실제 남은 시간처럼 단정하는 표현도 완화가 필요하다.

권고: 안전/보장/처방을 ‘가정에 따른 참고 추정’으로 바꾸고 임상적 진단·근육 증가를 보장하지 않는다. 식이·운동의 개인별 제한과 적용되지 않는 대상을 확인한다. 일반 건강 계산기라는 사실만으로 무면허 의료행위로 단정할 수는 없으나, 실제 질환 진단·치료·개인별 처방으로 발전하면 별도의 의료법 검토가 필요하다.

근거: [카페인 판정](C:/project/addseo/tools/caffeine-sleep-calc/app.js:273), [식단 처방 결과](C:/project/addseo/tools/diet-bmr-tdee-calc/app.js:158).

## 4. 금융·통계 데이터: 실측·공식과 실제 방법의 불일치

레버리지 백테스트는 연간 수익률을 일정한 월 복리율로 나눠 적립식 성과와 낙폭을 계산한다. 이 경로는 실제 월별 가격 경로가 아니다. 실제 기간별 적립 성과·최대 낙폭으로 표시하면 오해를 만든다. 원자료를 받았다는 주석만으로 모든 내장 값의 진위를 검증할 수 없다.

아파트 타임머신의 현재가·과거가는 고정 배열이며 거래 식별자·시점·선정 방법이 없다. 순자산 상위 백분위·평균 비교·도시 집값·세계 소득 등의 상당수도 기관명은 있지만 각 수치에 연결되는 표 ID·추출 파일·재현 절차가 부족하다. 인플레의 2026 CPI는 코드에서 추정치라고 하면서 화면에서는 공식 최신 실측처럼 소개한다.

권고: 실제 원자료와 일치하는 값만 ‘공식 집계/실측’으로 표시한다. 보간·예시·가정은 별도 표시하고 기준일·표 ID·단위·모집단·가공 방법을 제공한다. 증빙 전에는 실제 투자 실적과 현재 시세를 내세우는 기능의 노출을 줄인다. 확인되지 않았다는 이유만으로 데이터를 전부 조작이라고 판단하지는 않는다.

## 5. 무료 API에도 이용 조건이 있음

시장 데이터 코드는 `open.er-api.com`의 무료 환율 API를 사용한다. 제공자는 이용 페이지의 출처 링크를 요구하지만 공개 소스에서 해당 표시를 찾지 못했다. 상업적 환산 용도로 허용하는 것과 데이터를 재배포해도 된다는 것은 다르다. 이 부분은 위법 단정이 아니라 제공자의 이용 조건 미충족 가능성이다. [공식 무료 API 문서](https://www.exchangerate-api.com/docs/free)

Yahoo Finance 데이터를 공개 CORS 프록시로 요청하는 경로도 있다. CORS가 통과하거나 누구나 호출할 수 있다는 사실은 데이터의 저장·재배포·상업적 표시 권한을 증명하지 않는다. 허용된 API와 약관을 확인하고, 응답 시각 대신 고정 날짜가 붙는 표시도 바로잡아야 한다.

## 6. 테트리스: 상표·외관·이용허락 검토

[레트로 테트리스](https://simulab.kr/tools/game-tetris/)는 제목·URL·게임에 테트리스 명칭과 익숙한 7종 블록, 10×20판·색 체계를 사용한다. 저장소에서는 이용허락 근거를 확인하지 못했다. 권리자는 명칭·로고·블록·외관 등에 대한 권리를 명시한다. [권리자 공식 표시](https://tetris.com/products?defaultProduct=merch)

규칙이나 아이디어가 같다고 곧바로 저작권 침해라고 확정하는 것은 아니다. 다만 명칭·식별 표시·구체적인 화면과 자산의 유사성은 별도 문제다. ‘직접 코딩했다’거나 ‘팬 게임’이라는 표시만으로 해결된다고 보지 않는다. 라이선스를 확인하거나 독자 명칭과 시각 표현을 갖춘 블록 퍼즐로 재설계하고, 유사성이 큰 경우 권리 검토 전 공개 유지 여부를 결정하는 것을 권한다. 이름만 바꾸면 모든 문제가 사라진다는 뜻도 아니다.

## 7. 공유 URL과 기기 저장

공통 공유 함수는 입력한 모든 값을 쿼리 문자열에 넣어 주소창을 바꾸고 복사한다. 사주에서는 출생 연·월·일·시·성별, 다른 도구에서는 자산·소득·건강 관련 입력이 포함될 수 있다. 서버 방문 통계를 꺼도 공유 링크에 포함된 정보까지 보호되는 것은 아니다. 링크를 열면 수신자·브라우저 기록·호스팅 로그 등에 값이 남을 수 있다. 공유 버튼을 누르기 전부터 모든 입력이 서버에 전송된다는 뜻은 아니다.

권고: 공유할 필드를 허용목록으로 제한하고 민감하거나 상세한 개인 입력은 기본 제외한다. 복사 전에 포함 항목을 보여주고 사용자가 선택하게 한다. Base64 등으로 단순 인코딩하는 것을 비밀 보호로 설명하지 않는다. 생년월일·재무 조건의 기기 저장도 페이지에 알리고 지우기 기능을 제공한다.

## 8. 사이트 공통: 운영 연락처·기존 DB

실제 개인정보 문의 연락처가 없고, 기존 서버 자료의 보관·삭제·국외 처리 설정이 미확인이다. 현재 선택 통계·원격 랭킹·광고 송출은 꺼져 있어 신규 수집 위험은 줄었지만 기존 자료에 관한 의무를 자동으로 없애지는 않는다. 개인정보처리방침에 확인 중이라고 적는 것만으로 필수 항목을 충족했다고 볼 수는 없다. [현행 개인정보 보호법 제30조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029331583), [개인정보위 국외 처리 안내](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS292&mCode=C050010000&nttId=10972).

Supabase의 익명 관리자 RPC 권한을 차단하는 SQL 004는 준비돼 있으나 운영 적용을 사용자가 후순위로 남겼다. 예전 RPC가 실제로 계속 공개돼 있는지는 이번에도 확인하지 않았다. 화면 로그인이나 프런트엔드 설정만으로 서버 권한이 해결됐다고 판단해서는 안 된다. 운영 메타데이터 점검·접근 차단·보관기간·삭제 창구를 우선 확인해야 한다. 개인정보가 실제 노출됐다고 확인한 것은 아니다.

시장 시세 프록시·환율 API 등의 외부 요청도 현재 개인정보처리방침의 외부 서비스 목록과 대조가 필요하다. 전달되는 항목과 계약 관계를 확인하기 전 일괄적으로 제3자 제공 또는 국외 이전 위반이라고 단정하지 않는다.

## 9. 게임·추첨의 추가 오해 표현

사다리 설명에는 암호학적으로 안전한 난수·완전히 같은 1/N 확률을 보장한다고 적혀 있지만 로직은 `Math.random()` 기반의 가로선 생성이다. 균일한 순열인지 입증되지 않았고 암호학적 난수라는 설명도 코드와 맞지 않는다. 공정성 보증을 제거하거나 검증한 난수·추첨 방식으로 바꿔야 한다.

로또·더치페이·사다리는 현재 코드에서 실제 돈을 결제·예치하거나 환금성 보상을 지급하는 기능을 확인하지 못했다. 가상 추첨이라는 이유만으로 곧바로 불법 도박이라고 판단하지 않는다. 실제 판돈·유료 응모·환금·경품과 결합한다면 판단이 달라진다. 광고 사업자의 도박 관련 콘텐츠 제한은 형사상 불법 여부와 별도로 검토한다.

## 10. 상대적으로 유지하기 쉬운 아이템

평수 변환·할인율·만나이·평단가 산술·일반 정산·설비 ROI처럼 입력 조건을 그대로 계산하는 도구는 이번 점검에서 위 유형의 특별한 규제 위험을 뚜렷하게 찾지 못했다. 오류·공유·개인정보·저작물 문제까지 없다는 보증은 아니다. 행사 달력은 공식 출처·확인일·실제 회차·미확인 요금을 구분하는 현재 체계를 유지한다. 공공기관 행사라도 포스터·사진·설명문에는 별도 권리가 있을 수 있으므로 이용허락 유형을 확인한다. [공공누리 유형 안내](https://www.copyright.or.kr/gov/nuri/rule_info/index.do)

아기 이름 도구는 공식 순위·출생 인원 표시를 중단해 현재 후보 탐색 범위로 운영하고 있다. 음주 계산도 운영 종료 안내로 전환된 상태다.

1. 사주·성향의 실제 투자 추천과 원금 보장, 카페인 수면 안전·효과 보장부터 제거하거나 해당 기능 노출을 보류한다.
2. 월급·실업급여·주담대·물가·순자산의 확인된 오류를 고치고 미지원 조건과 검토일을 공개한다. 세금·연금 수식도 같은 기준으로 검산한다.
3. 상세 개인 입력이 공유 URL에 들어가는 방식을 바꾸고 실제 개인정보 문의·삭제 창구를 마련한다.
4. Supabase 운영 권한과 보관·삭제 상태를 별도 확인한다. 후순위 요청을 존중해 이번 진단에서 임의로 운영 DB를 변경하지 않는다.
5. 테트리스 권리와 금융 데이터 이용 조건을 확인하고, 통계·실측 주장을 원자료와 대조한 후 유지 여부를 결정한다.

이번 점검 결과는 보고서로 남겼으며, 위 기능의 삭제·중단이나 운영 배포는 수행하지 않았다.
