# 2026-10-26 가족정보 초기 보강

사용자 요청에 따라 9개 사이트 예약 각각 매 실행 공식 상세 공지 최소 15건 조사 기준을 적용했다. 검색 요약·단순 목록·접근 차단·본문 없는 이동 화면은 완료 조사에서 제외한다. 같은 공지의 메뉴/호스트 차이와 같은 프로그램의 회차는 합산하지 않는다.

이번 실행 ID는 `baseline-2026-10-26`이다. 상세 검토는 공개 확정뿐 아니라 종료 제외·조건 미확인 보류를 포함한다. 조사 수가 곧 게시 수는 아니다.

| 항목 | 상세 조사 | 현재 공개 유효 | 공개 15건 대비 부족 |
| --- | ---: | ---: | ---: |
| 아이 체험·교육 | 23 | 7 | 8 |
| 도서관·육아지원센터 | 21 | 3 | 12 |
| 육아·가족 지원사업 | 18 | 7 | 8 |
| 공공 캠핑장·휴양림 | 21 | 4 | 11 |
| 어린이 공연·전시 | 49 | 15 | 0 |
| 키즈 팝업·캐릭터 행사 | 16 | 1 | 14 |
| 브랜드 세일 | 15 | 7 | 8 |
| 가족 외식·시설 할인 | 19 | 16 | 0 |
| 축제·지역 행사 | 17 | 13 | 2 |

신규 공개 레코드는 50건이다. 기존 2건과 합쳐 신규 7분야의 정본은 52건이며, 파인캐릭터 전시 1건은 공연·전시와 캐릭터 행사 양쪽에서 같은 ID로 사용한다. 기존 세일·축제 원본과 확인일은 보존했다. 위 표는 확인일 현재 건수이고, 운영 시각에 따라 종료 여부가 바뀔 수 있다.

초기 공개는 서울·인천의 공공 프로그램, 서울시 지원사업, 경기 과천 서울랜드, 대구·충북·경북 예약 공지에 집중되어 있다. 도서관·팝업·외식과 다른 권역/사업자 확대가 남았다. 후속 예약은 공개 15건 미만 분야를 우선하고, 특정 시설의 유사 혜택으로 숫자를 채우지 않는다. 현재 16건의 시설 할인도 외식 자료 확보 완료를 뜻하지 않는다.

부모교육 포털의 `CW_SYSNM`/`CW_DOMAIN` 미완성 값, 이미지 본문의 실제 회차·연령·금액 미확인, 팝업의 종료·이동 화면 등은 내부 조사 기록으로 남겼다. 공개 카드에 미확인 참가비를 무료로 표시하지 않았다. 지원사업은 상시/개인별 기한과 거주·소득·중복수혜 조건을 구분한다.

검증: 103개 테스트, 전체 빌드, 공개 파일/내부자료 제외 검사, 기존 축제·세일 생성물 검사 통과. 360px 모바일에서 개인별 신청기한과 카드 줄바꿈을 확인했다. 실제 배포 결과는 `docs/family-info-automation-status.json`의 deployment에 기록한다.

```powershell
npm run family:audit -- --run=baseline-2026-10-26 --require-minimum
```

매 예약은 이 초기 실행 ID를 재사용하지 않고 이번 실행의 고유 ID를 기록한다. 최소 조사 미달 시 점검 명령은 종료코드 2를 반환하며, 미달 상태를 완료로 보고하지 않는다.
