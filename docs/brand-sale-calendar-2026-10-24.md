## 자료 이용과 법적 검토

공개된 공지라는 사실이나 출처 표기만으로 영리 재게시 허락이 생기지 않는다. 이번 구현은 소수의 행사 일정과 최소 조건을 직접 편집한 범위로 한정한 운영 판단이며, 업체의 포괄적 이용허락이나 법적 적합성에 대한 확정 의견이 아니다.

- [저작권법 제93조](https://law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0093&lsiSeq=283335&urlMode=lsScJoRltInfoR)는 반복적·체계적인 일부 데이터 이용도 일정 요건에서 규율한다. 상품 DB 미러링과 허락 없는 대량 수집을 도입하지 않았다. 수동 편집이라는 이유만으로 항상 적법하다고 단정하지 않는다.
- TOPTEN·H&M 등 약관의 콘텐츠 영리 이용 제한은 잔여 검토 대상이다. 표현·사진·포인트 표·가격표를 전재하지 않고 행사명·기간 등의 최소 사실만 정리한다. 권리 주장이나 적용 범위 의문이 구체화되면 해당 일정은 `held`로 전환해 링크 안내만 남기고 이용허락 범위를 확인한다.
- [공정위 추천·보증 심사지침 개정 안내](https://m.korea.kr/briefing/pressReleaseView.do?newsId=156764553)의 경제적 관계 표시 기준을 고려한다. 향후 제휴 수수료·협찬이 생기면 게시물 앞부분과 해당 링크 가까이에 명확히 표시한다. 현재 이용 후기나 공식 제휴·보증을 가장하지 않는다.
- 적립·페이백·사은품·할부·배송을 즉시 가격 할인과 구분한다. 종료·재확인·회원·품목·매장·결제 조건 및 조기 종료 가능성을 표시한다.
- 외부 업체에 연락하거나 계약·제휴 계정을 생성하지 않았다. 권리 확보가 필요한 자동 수집은 허락·약관·호출 제한을 검토한 뒤 별도 구현한다.

## 데이터 수정 절차

1. `data/deals/sources.json`에서 공식 운영사·호스트·원문·권리 검토 메모를 확인한다.
2. `data/deals/reviewed.json`에 이벤트 단위로 작성한다. `periodSourceUrl`, 실제 `checkedAt`, 시작/종료일, 조건, 이용 채널, 게재 범위가 필수다. 날짜 미확인은 월간 일정으로 발행하지 않는다.
3. 단일 방송의 게시기간을 방송기간으로 쓰지 않는다. 전체 행사와 개별 혜택 기간, 장기 배송·회원 혜택을 구분한다. 구매 채널 미확인은 `unknown`이다.
4. `npm run deals:audit`로 검증한다. 외부 수집이나 확인일 갱신은 하지 않는 명령이다.
5. `npm run build`, `npm test`, `node scripts/check-public.mjs`, `node scripts/build-publishing-ui.mjs --check` 후 모바일·데스크톱 화면을 확인한다.
6. 검증을 통과한 변경을 GitHub main으로 배포하고 운영 페이지를 확인한다. 내부 원본·보고서·스크립트·테스트는 공개 산출물에 포함하지 않는다.

생성물 `tools/parenting-deals/data.js`와 HTML은 직접 수정하지 않는다. 마크업은 `scripts/templates/brand-sale-calendar.html`, 생성기는 `scripts/build-parenting-deals.mjs`이다.

## 갱신과 화면 동작

- 공지 확인 후 7일을 넘으면 ‘재확인 필요’로 구분하고 진행 중·임박 집계에서 제외한다. 이 동작은 **새 공지를 수집하는 기능이 아니다**. 행사 종료는 한국 날짜·공개 종료시각을 기준으로 판정한다.
- 방송 종료시각이 없으면 방송일 이후 실제 진행 여부를 보장하지 않는다. 방송일에는 ‘방송일 · 진행 확인’으로 표시한다.
- 달력/목록, 분야·브랜드·채널·상태·검색 조건, 월 이동, 날짜별 일정, 주별 넘친 일정 더보기를 제공한다. 달력은 최대 3개 행을 표시하고 숨은 일정 수와 목록 진입을 명시한다.
- JavaScript가 꺼진 경우에도 정적 달력·목록·출처·확인일을 제공하며 정적 안내임을 명시한다. 실시간 확인 서비스라고 홍보하지 않는다.
- 별도 정기 수집 작업은 만들지 않았다. 정기 유지보수를 연결할 때는 위 검토 절차와 실제 원문 대조, 권리 보류, 테스트·배포 검증을 포함해야 한다.
