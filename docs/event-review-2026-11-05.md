# 전국 축제 일정 검토 · 2026-11-05 (한국시간)

이번 주말(11/7~8)과 11/22까지 시작하는 일정을 우선 검토했다. 기존 기록에서 6건을 재확인하고 22건을 추가했다. 11/5 이후 일정이 있는 수록 행사는 30건이며 17개 지역 필터에 모두 일정이 있다. 목록은 확인한 행사의 선별 목록이다.

## 역할과 결과 전달

- Codex (약 80%): 전국 후보를 기존 목록과 대조하고 날짜, 장소, 운영 시간, 비용과 예약 조건을 공식 공지에서 확인한다. 출처가 충돌하면 주최 측의 해당 회차 공지를 기준으로 결정하고, 데이터·빌드·배포를 담당한다.
- Antigravity (약 20%): 공개 자료를 읽기 전용으로 조사한다. 미등록 후보 또는 Codex가 건넨 위험 항목에 대해 행사명, 날짜, 장소, 공식 URL, 불일치 여부를 회신한다. 확인하지 못한 사실은 분리한다.
- 결과는 행사명과 공식 URL을 기준으로 한 번 대조한다. Antigravity 답변 자체를 출처로 게시하지 않고 실제 원문을 링크한다. 주최 측 공식 공지를 직접 확인할 수 없으면 관광기관의 행사별 자료를 사용하고, 요금·회차·예약이 확인되지 않으면 미확인으로 표시한다.

이번 실행에서 Antigravity의 권역별 광역 검색은 응답 시간 내에 완료되지 않았다. Codex가 선정한 3건과 주최 측 URL을 보내 다시 요청했고, 아래 날짜·장소에 대한 회신을 받아 원문과 대조했다.

대한민국 구석구석, 문체부, 지역 관광 포털에서 후보를 찾고 개최기관·지자체 공지를 우선 확인했다. 문체부 축제 달력의 한국관광공사 연동 항목은 독립된 출처 두 곳으로 세지 않는다. 네이버 검색 결과 페이지는 접근 제한으로 확인하지 못했다. 파주 운정호수공원은 10/31 불꽃축제가 종료되어 12/31까지 운영되는 불빛정원만 별도 수록했다.
