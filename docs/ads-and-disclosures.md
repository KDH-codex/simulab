# 광고 배치와 이용 고지 점검 · 2026-10-23

현재 AdSense는 사용자 설명상 승인 대기 중이다. Google 계정의 심사·광고 설정 화면을 직접 확인한 것은 아니다.

## 확인한 문제와 수정

- 지난 개편의 `assets/css/refresh.css`가 기존 광고 슬롯을 일괄 숨겼다. 광고 스크립트도 제거되어 있었고 `adsEnabled` 값은 실제 AdSense 로더에 연결되지 않았다. 따라서 Google에서 승인돼도 현재 소스만으로 자동 광고가 시작되지는 않는다.
- 기존 수동 광고 모양의 `data-ad-slot="auto"`는 실제 광고 단위 ID가 아니었다. 이 빈 광고 태그와 중복 슬롯을 제거했다.
- 홈과 공개 도구에 한 곳씩 준비 영역을 정적으로 배치했다. 홈은 추천 도구 다음, 행사 달력은 목록 다음, 다른 도구는 해설 앞 또는 본문 하단이다. 운영 종료된 음주 계산 페이지, 공개 실행을 보류한 블록 퍼즐과 관리자·약관·개인정보 페이지에는 배치하지 않는다. 총 50곳이다.
- 준비 영역에는 ‘광고 / 광고 게재 준비 중’만 표시한다. 실제 광고, 링크나 가짜 광고 이미지를 표시하지 않으며, 이 영역이 자동 광고의 고정 위치가 된다는 의미도 아니다.
- 51개 공개 도구에 제목 아래 또는 행사 검색 전에 분야별 이용 안내를 넣고, 하단에 면책고지·약관·출처 링크를 제공한다. JavaScript 실행 전에도 보이도록 정적 HTML로 생성한다. 통계·건강·금융·오락을 구분하고, 사주·투자 성향 테스트가 금융 조언으로 분류되던 순서 문제도 수정했다.
- 안내문은 무조건적인 책임 배제가 아니라 정보의 용도와 한계를 설명한다. 기존 약관의 고의·중과실 등 배제할 수 없는 책임을 유지한다. 종료된 음주 계산 페이지의 검색 설명과 상단에 남아 있던 ‘안전 운전 가능 시각’ 제공 문구도 실제 운영 종료 상태에 맞췄다.

## 승인 이후 필요한 작업

1. AdSense 사이트 상태가 ‘준비됨’인지, 소유권 확인·ads.txt 경고가 없는지 확인한다. 현재 공개된 publisher ID, 메타 태그, ads.txt는 유지한다.
2. 자동 광고를 유지하려면 실제 AdSense 공통 코드를 연결해야 한다. **현재 `adsEnabled: true`로만 바꾸어도 광고가 켜지는 구조가 아니다.** 승인 대기용 표시도 이때 제거하거나 실제 수동 광고로 교체한다.
3. 정확히 지정한 자리에 광고를 넣으려면 AdSense에서 발급한 실제 숫자 광고 단위 ID가 필요하다. `data-ad-format="auto"`는 반응형 형식 설정이며, `data-ad-slot="auto"`를 의미하지 않는다. 자동 광고는 Google이 위치를 결정한다.
4. 공개 운영 연락처를 마련하고 개인정보처리방침을 실제 광고 공급업체·쿠키·제3자 이용과 광고 설정 링크에 맞춰 갱신한다. EEA·영국·스위스 이용자에게 광고를 게재한다면 Google 인증 CMP 등 해당 지역의 동의 요건을 적용한다. 현재 방문 통계 선택창은 광고 CMP를 대신하지 않는다.
5. 계산 입력·결과·게임 조작·행사 필터와 광고가 혼동되거나 겹치지 않도록 자동 광고 미리보기와 제외 영역을 점검한다. 콘텐츠보다 광고가 많아지지 않게 유지한다. 실제 모바일 광고에서 화면 밀림도 확인한다.

광고 자리를 만드는 것만으로 승인이나 수익이 보장되지 않는다. 면책 안내의 가시성을 강화해도 원문·수식·적용 기준의 정확성을 계속 점검해야 한다. 이 점검은 전체 콘텐츠에 대한 법률 적합성 인증이 아니다.

## 수정·검증

공통 문구는 `assets/js/core-ui.js`의 `getToolNotice`에서 관리한다. `scripts/build-publishing-ui.mjs`가 정적 고지와 광고 준비 영역을 생성하며 `npm run build`에서 실행한다. 생성물을 직접 고치기보다 공통 문구·생성기를 수정한다.

```powershell
npm test
npm run build
node scripts/build-publishing-ui.mjs --check
node scripts/check-public.mjs
```
