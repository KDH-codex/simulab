2026-11-05 사용자 요청에 따라 현재 작업 폴더를 정리하고 실제 Antigravity **Argon Medium**으로 독립 검토를 진행했다. 이어 같은 모델·에포트의 같은 대화에 오류 정정과 실행계획 보완을 요청했다. 두 요청 모두 정상 종료했다. 이 문서는 원문 지적을 실제 코드·화면과 대조해 통합한 계획이며, 아래 UI 수정은 아직 구현·배포하지 않았다.

- 운영 사이트를 이번 검토에서 새로 배포하거나 현재 원격 버전을 다시 확인하지 않았다. 과거 배포 기록과 이번 검토 완료를 운영 반영 완료로 합치지 않는다.

### 1. Stitch와 연결되는 시각 체계·이미지 배치

### 2. 탐색 흐름·모바일 조작성 보완

1. 상세 페이지의 태그를 실제 필터 결과로 연결한다. 달력에서의 태그는 현재 달력 필터 동작을 유지한다.
2. 고정 바에 활성 추가 조건과 개별 해제를 표시한다. 필터를 지난 뒤에만 고정되는 현재 기준, 원래 필터와 공유하는 상태를 유지한다.
3. 작은 대표 카드 조작부·고정 바 버튼의 실제 터치 영역을 넓힌다. 아이콘 크기와 누르는 영역을 분리하고 320px 구도에서 검증한다.
4. 모달의 태그·장소 안내, 주간 전체 복귀, 선택된 날짜의 결과 안내를 연결한다. 모달 태그 처리도 현재 페이지 종류에 맞게 연결한다.

대상: `assets/js/festival-platform.js`, 생성기의 모달·상세 마크업, 관련 CSS. 완료 조건은 실제 클릭·키보드 조작으로 목록 연결, 선택 상태, 닫기·복귀를 확인하는 것이다.

| 요소 | 제안 명세 | 모션 줄이기 |

위 수치는 구현 시작 기준이며 실제 조작과 화면 녹화로 조정한다. 첨부 UI·모션 목록을 모두 추가하는 것이 목표가 아니다. 각 효과는 무엇이 바뀌었는지 이해하는 데 기여해야 한다. 새 모션 라이브러리 도입 여부는 현재 구현으로 부족한 점이 확인된 뒤 결정한다.

### 4. 화면 대조·재검증 후 기존 배포

- 홈 첫 화면 / 필터 통과 / 주간 달력 / 모바일 상세를 Stitch와 나란히 비교한다. 의도적인 차이와 개선 이유를 기록한다.
- 1440/390/320px, 긴 제목, 이미지 없음, 0건, 느린 로딩·예보 실패, 키보드, 모션 줄이기를 확인한다. 정지 캡처만으로 동작을 승인하지 않는다.
- 변경한 동작의 의미 있는 회귀 검사와 `npm test`, `npm run build`, `node scripts/check-public.mjs`를 통과시킨다. 이미지 다양성·글자 크기를 기계적으로 강제하는 구현 복제 테스트는 만들지 않는다.
- 다음 구현 후 Antigravity 재검토도 **Argon / medium**을 사용하고 실제로 확인한 범위를 기록한다. 통과 후 기존 GitHub main → Cloudflare 절차로 반영하고 운영 반영을 별도로 확인한다.

이번 요청에서 완료한 것은 **폴더 정리·독립 검토·정정·실행계획 통합**이다. 홈페이지 UI 수정과 배포는 이 계획의 후속 실행 단계다.
